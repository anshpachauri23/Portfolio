## 📊 Complete Project Catalog

### **Project 1 - Mathematical Integration System**
- **Technology**: C Programming, Numerical Methods
- **Description**: Numerical integration system using rectangle approximation method for calculating area under x² curve
- **Key Features**:
  - **Rectangle Approximation**: Divides integration area into rectangles for estimation using midpoint method
  - **Iterative Precision**: Continues until difference between successive estimates is less than specified precision
  - **Error Handling**: Handles illegal cases (lower > upper, precision ≤ 0) with appropriate error codes
  - **Convergence Control**: Maximum iteration limit (10,000,000) to prevent infinite loops
  - **Mathematical Function**: Specifically integrates x² function with configurable bounds
- **Skills Demonstrated**: Numerical Methods, Mathematical Programming, C Function Design, Error Handling, Algorithm Implementation

### **Project 2 - Bit Manipulation Utilities**
- **Technology**: C Programming, Bit Operations, Low-level Programming
- **Description**: Comprehensive toolkit for bit-level operations, pattern matching, and file processing
- **Key Features**:
  - **Bit Counting**: Counts minimum bits needed to represent unsigned integers using right shift operations
  - **Pattern Matching**: Counts specific bit patterns (0s and 1s) in numbers using modulo and shift operations
  - **Pattern Finding**: Searches for needle patterns within haystack numbers using bit extraction
  - **Bit Inversion**: 32-bit number inversion by swapping upper and lower 16-bit halves
  - **File Processing**: Reads test cases from files and applies bit operations with conditional logic
- **Skills Demonstrated**: Bit Manipulation, Low-level Programming, C Programming, File I/O, Pattern Matching

### **Project 3 - Word Search Matrix**
- **Technology**: C Programming, String Processing, Matrix Operations
- **Description**: Word search system for finding words in 2D character matrices with directional search
- **Key Features**:
  - **Matrix Processing**: Handles 2D character arrays (MAXN x MAXN) for word searching
  - **Directional Search**: Searches in 8 directions (horizontal, vertical, diagonal) using direction vectors
  - **String Extraction**: Extracts words from matrix starting at specific positions and moving in specified directions
  - **Boundary Checking**: Validates matrix bounds during word extraction
  - **Multiple Word Search**: Processes multiple search words with match counting
  - **Pattern Recognition**: Identifies exact string matches in complex matrices
- **Skills Demonstrated**: String Processing, Matrix Operations, C Programming, Boundary Validation, Multi-directional Search

### **Project 4 - Course Management System**
- **Technology**: C Programming, Dynamic Memory Management, Data Structures
- **Description**: Course information management system with comprehensive memory tracking and file processing
- **Key Features**:
  - **Dynamic Memory**: Custom malloc/free wrapper functions with total memory tracking
  - **Data Structures**: Course information structures with dynamic grade arrays and course codes
  - **File Processing**: Reads course data from files with error handling and validation
  - **Memory Tracking**: Monitors allocated memory with detailed tracking and reporting
  - **Sorting Algorithm**: Implements bubble sort for course code ordering
  - **Memory Cleanup**: Comprehensive memory deallocation with proper cleanup procedures
- **Skills Demonstrated**: Dynamic Memory Management, Data Structures, File I/O, Error Handling, Memory Tracking, Sorting Algorithms

### **Project 5 - Assembly Language Programming**
- **Technology**: x86-64 Assembly, Systems Programming, Low-level Optimization
- **Description**: Multiple assembly language programs demonstrating low-level programming and system calls
- **Key Features**:
  - **Vector Operations**: Assembly implementation of vector dot product calculations (5-element arrays)
  - **Prime Number Counting**: Assembly algorithm for counting prime numbers between 2-10 using division and modulo
  - **Loop Implementation**: Assembly loops with ASCII character output and system calls
  - **System Calls**: Direct sys_write and sys_exit system calls for I/O operations
  - **Register Management**: Efficient use of x86-64 registers (rax, rbx, rcx, rdx, rsi, rdi)
  - **Memory Operations**: Direct memory addressing and array element access
- **Skills Demonstrated**: Assembly Language, Systems Programming, Low-level Optimization, System Calls, Register Management

### **Project 6 - Vector Sorting Algorithm**
- **Technology**: x86-64 Assembly, Sorting Algorithms, Systems Programming
- **Description**: Advanced sorting algorithm implementation in assembly language with I/O operations
- **Key Features**:
  - **Sorting Algorithm**: Assembly implementation of sorting algorithms for 9-element arrays
  - **Array Manipulation**: Direct memory access and array operations with indexed addressing
  - **System Output**: Assembly system calls for printing individual digits and array elements
  - **Function Implementation**: Assembly functions for digit printing and array display
  - **Loop Control**: Complex loop structures with conditional branching and iteration
  - **Memory Management**: Stack frame management with push/pop operations and function calls
- **Skills Demonstrated**: Assembly Language, Algorithm Implementation, Systems Programming, Function Calls, Stack Management
